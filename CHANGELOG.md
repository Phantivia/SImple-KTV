# Changelog

## 0.1.1 — Windows BAT launchers

- Add double-click GPU/CPU start, safe stop, log viewer and diagnostic BAT files.
- Centralize Windows startup with Docker detection, Desktop auto-open when available, local-endpoint guard, Compose version check, Linux-container check, live logs and error exit codes.
- Preserve volumes on all launcher paths; no silent GPU-to-CPU fallback.
- Add Windows PowerShell 5.1 / mocked-Docker launcher regression tests to CI.
- Add a guarded local uploader for the existing `Phantivia/SImple-KTV` public repository.
- Connector initialized the remote repository but subsequent source-tree writes were blocked; this ZIP is the complete delivery.
- No claim of new GPU-model, audio-device or generative-harmony validation.


## 0.1.0 — 2026-09-05

Initial engineering preview: local MP3 import; immutable projects and revisions; RoFormer adapters and model registry; native Rubber Band R3 transpose; AudioWorklet microphone capture; waveform selection and safe punch/erase; pYIN/TorchCREPE pitch adapters; editable PSOLA correction; explicitly labeled DSP harmonies; FFmpeg/Pedalboard vocal effects; gain automation, stereo mix and two-pass exports; monochrome pixel-wave UI; Docker source builds; public-repository publishing helpers; CPU/Node/UI test evidence.

Known release gates: first Docker dependency/build verification, target RTX 5090 Laptop inference and quality evaluation, secure-origin browser/real audio-device end-to-end validation, newer checkpoint selection and genuinely generative harmonization. No remote repository or container registry image is implied by this changelog.
